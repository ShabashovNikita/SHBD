## ADDED Requirements

### Requirement: Независимость тестов от языка системы

Юнит-тесты, которые проверяют форматирование чисел, ДОЛЖНЫ (SHALL) сами задавать язык
(`Locale`) на время проверки и возвращать прежний язык после неё. Результат таких тестов
не должен зависеть от языка Windows или Linux, на котором их запускают.

#### Scenario: Запуск на русской Windows

- **WHEN** `FoodEntryEditMathTest` запускается на компьютере с русским языком системы
- **THEN** проверки формата `21.3` проходят, потому что тест задаёт `Locale.US`

#### Scenario: Русский формат числа

- **WHEN** число 21,3 показывается при языке `ru`
- **THEN** текст равен `21,3`, а обратный разбор этого текста даёт исходное значение

### Requirement: Независимость сетевых тестов от порядка таймеров

Тест таймаута чтения тела ответа ДОЛЖЕН (SHALL) проверять тип ошибки (`AiError.Network`)
и принимать любой из текстов таймаута, которые выдаёт связка JDK + OkHttp/Okio
(`timeout` или `Read timed out`).

#### Scenario: Сработал таймер сокета Java

- **WHEN** чтение тела ответа прерывается с текстом `Read timed out`
- **THEN** тест проходит: ошибка — `AiError.Network`, в тексте есть признак таймаута

#### Scenario: Сработал сторожевой таймер Okio

- **WHEN** чтение тела ответа прерывается с текстом `timeout`
- **THEN** тест проходит так же
