# Предложение: «Твой план» из карточки «Питание» и без «Планирования приёмов пищи»

## Зачем

Пункт «Изменить цель калорий» в меню «⋮» карточки «Питание» открывает раздел Профиль → Цели с
множеством настроек. Пользователь ждёт тот же простой экран, что в опросе: «Твой план» с нормой,
ползунком калорий, сроком достижения цели и БЖУ. Норма при этом должна считаться по текущему
весу из блока «Вес», а не по весу на момент опроса.

В разделе Профиль → Еда и запись есть переключатель «Планирование приёмов пищи» (Meal
planning). Он не нужен: план питания на неделю появится в разделе «Рацион».

## Что меняется

- «Изменить цель калорий» открывает экран «Твой план» — такой же, как в опросе: «<план> из
  <норма> ккал», ползунок, дефицит/профицит и срок достижения цели, БЖУ только для просмотра,
  предупреждение при дефиците больше 1 кг в неделю.
- Норма (TDEE) считается по профилю с последним весом из блока «Вес». Начальный план — норма
  минус дефицит (плюс профицит) темпа из профиля.
- Кнопка «Сохранить» записывает в профиль текущий вес и выбранные калории; БЖУ пересчитываются из
  калорий. «Назад» закрывает экран без изменений.
- Экран опроса и новый экран используют одну общую разметку.
- Переключатель «Планирование приёмов пищи» и его пояснение удаляются из Профиль → Еда и запись;
  если он был включён, он выключается один раз при запуске.

## Возможности

### Новые возможности
- `calorie-plan`: экран «Твой план» из Дневника — расчёт нормы по текущему весу и сохранение плана.
- `food-entry-settings`: раздел Профиль → Еда и запись без «Планирования приёмов пищи».

### Изменяемые возможности
- `diary-dashboard`: «Карточка Питание» — пункт «Изменить цель калорий» ведёт на «Твой план».

## Дополнение (29.10.2026): желаемый вес на «Твоём плане»

Под Белками, Углеводами и Жирами — блок «Желаемый вес» с тем же колесом веса, что в опросе. В
пояснении: «Ваш текущий вес: N кг. Цель по весу: M кг.». Срок достижения цели пересчитывается
сразу, «Сохранить» записывает желаемый вес в профиль. При цели «Поддерживать» блока нет.

## Дополнение (29.10.2026): «Твой план» из «Приёмов пищи»

На экране «Приёмы пищи» у сводки с калориями — такая же кнопка «⋮» с пунктом «Изменить цель
калорий»; нажатие на саму сводку тоже открывает «Твой план». Изменяемая возможность:
`diary-block-screens` («Экран «Приёмы пищи»»).
